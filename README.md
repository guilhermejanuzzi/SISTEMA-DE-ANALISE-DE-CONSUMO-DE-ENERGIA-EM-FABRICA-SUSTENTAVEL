# SISTEMA-DE-ANALISE-DE-CONSUMO-DE-ENERGIA-EM-FABRICA-SUSTENTAVEL
Este projeto realiza a análise do consumo de energia elétrica de uma fábrica sustentável a partir de um arquivo CSV, utilizando bibliotecas de ciência de dados em Python. O objetivo é identificar padrões de consumo, analisar o desempenho energético das máquinas e destacar dias de alto consumo.

## Funcionalidades
- Leitura e validação de dados a partir de arquivo CSV
- Tratamento de dados inválidos ou ausentes
- Cálculo de métricas estatísticas (média, soma e desvio padrão)
- Análise de consumo total, médio e variabilidade por máquina
- Identificação dos dias de maior e menor consumo
- Criação de gráficos de dispersão e gráficos de linha
- Classificação de dias com alto consumo energético

## Tecnologias Utilizadas
- Python 3
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Visualizações
- Gráfico de dispersão: relação entre horas trabalhadas e consumo de energia
- Gráfico de linhas: consumo de energia ao longo dos dias por máquina

## Objetivo
Projeto desenvolvido com fins educacionais para praticar análise de dados, visualização gráfica e manipulação de datasets no contexto de sustentabilidade e eficiência energética industrial.
